## 8. Recommandations pratiques pour YULCOM

Compte tenu du profil de YULCOM Technologies (intégration IT, GED, infrastructure, digitalisation), les sources les plus rentables à mettre en **veille active** sont :

### Priorité 1 — Veille quotidienne
1. **DGCMEF + Revue des Marchés Publics** — accès libre, indispensable
2. **UNGM** — créer un compte société et configurer les alertes sur les codes UNSPSC IT :
   - `43xxxxxx` — Information Technology Broadcasting and Telecommunications
   - `81xxxxxx` — Engineering and Research and Technology Based Services
3. **PNUD-BFA** — bureau local très actif sur les AO informatiques

### Priorité 2 — Veille hebdomadaire
4. **Banque mondiale** — alerte par pays "Burkina Faso" + secteur ICT/Digital
5. **BAD** — page pays Burkina Faso + AGPM
6. **UEMOA + BCEAO** — basés à Ouaga/Dakar, AO IT récurrents (matériel informatique, IA, maintenance)

### Priorité 3 — Veille mensuelle
7. **CEDEAO + ARAA** — projets régionaux
8. **UE / TED + AFD + KfW + GIZ** — bailleurs bilatéraux européens
9. **BID** — projets PDPS et autres

### Configuration recommandée

- **Centraliser** les alertes email dans une boîte dédiée (ex : `veille-ao@yulcom.tech`)
- **Tableau de suivi** avec colonnes : Source • Date publication • Référence • Date limite • Bailleur • Estimation budget • Décision Go/No-Go
- **Codes UNSPSC à enregistrer** sur UNGM (limite : 7 codes prioritaires)
- **Mots-clés FR/EN** : *digitalisation, GED, ECM, dématérialisation, système d'information, ERP, infrastructure réseau, cybersécurité, biométrie, document management, IT services, software development*
